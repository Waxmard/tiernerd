TierNerd UI directions

Design study — sample data, nothing is saved

Four directions for the same favorites: handwritten, editorial, after-dark and playful. Stronger green means more preferred; bare scores are available for reference.

Applies to Ranked list. Order shows preference, not an exact score scale.

Only completed rankings appear in these lists. This study assumes unfinished additions are discarded; it does not change the app’s storage.

Stronger green = more preferred. Paler green = less preferred.

Handwritten journal

A personal, ruled page for the favorites you keep coming back to.

Editorial ranking

A considered shortlist, with a strong lead and a quieter supporting cast.

Dark playlist

A compact after-dark collection, with clear rows and a steady rhythm.

Playful collection

A small collection of keepsakes, arranged as bright, tactile tiles.

What could go in the margins?

These native emoji are decorative samples, not saved customization. Their appearance varies by platform. The checkbox changes all four previews without changing names, ranks or scores.

Native emoji

No library needed to display them. Saving choices for lists and items still needs validated fields, forms, API contracts and a migration.

Existing Ionicons

Already installed, with consistent rendering. Choosing your own would still need a selector and persisted icon identifiers.

Real item images

A separate feature could reuse the existing item image_url contract. The inspected client has no list-artwork contract. Image search adds provider access, privacy, content rights, attribution and hosting decisions—not Google scraping or a portable Siri integration.

The four directions use different surface and type treatments while sharing the strong-to-pale preference colors. Caveat is the only external font, loaded from Google Fonts; other text uses system fonts. No private data or application services are used.

Action and choice specimens are static, not working app controls. This study does not change the app’s theme preferences, ranking, saved stickers or image search.
